# Mini Log 0.1.0

写真を並べて、一日の小さな記録を作るWindows向けツールです。

## できること

- 画像D&D追加とカット並べ替え
- 静止画 / 動画風、Zoom / Pan、表示時間調整
- カットCaption（フォント・サイズ・位置・Motion）
- BGM / Cut Audio
- Preview、Project保存 / 復元、MP4書き出し
- 春 / 夏 / 秋 / 冬テーマ

## 使い方

1. `MiniLog-0.1.0-windows.zip` をダウンロード
2. ZIPを展開
3. `MiniLog.exe` を起動
4. 写真をドラッグ＆ドロップ、または「画像を追加」から入れる
5. Cutカードを並べ替え、静止画 / 動画風・動き・表示時間を調整する
6. 必要に応じてCaption、BGM、Cut Audioを設定する
7. 「プレビューを作成」で全体のテンポと流れを確認する
8. 「MP4を書き出す」で完成動画を保存する

未署名EXEのため、Windows SmartScreenが表示される場合があります。ZIPは展開したフォルダごと使用してください。第三者ソフトウェアの案内は配布物内の `THIRD_PARTY_NOTICES.txt` を確認してください。
