# Mini Log 0.1.0 — note用メモ

## 作った目的

複数の静止画像を、重い動画編集ソフトを開かずに短い縦型VlogへまとめるためのWindows向けツールです。

## 主な機能

画像D&D、静止画 / 動画風、Zoom / Pan、カットCaption、BGM、Cut Audio、Preview、MP4書き出し、Project保存 / 復元、季節テーマを備えています。

## 使い方

画像を追加し、順番・秒数・Caption・音声を調整してPreviewを確認し、MP4を書き出します。

## 0.1.0の特徴

写真ベースの短いVlog作成に必要な編集だけへ絞り、Previewで全体の流れを確認してから書き出せます。

## 公開方針

Mini Log 0.1.0はGitHub Releasesで無償公開予定です。ZIPを展開して使うWindows版で、Installer・署名・自動Updateはありません。今後の機能追加や配布形態は未定です。
